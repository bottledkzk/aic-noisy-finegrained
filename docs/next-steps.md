# 后续改进

最值得继续做的是在固定 SCE2 分数上测**置信度加权的半松弛 OT**。既有配对实验支持保留软先验，下一步要确认先验主要在帮哪些预测，尤其是它是否适合用于模型本来非常有把握的样本。以下是待验证方向，先用具有合法使用权限的独立数据做对照。

## 1. 先定位 SOT 的收益和破坏

把模型、五视图、检索库、弱图与查询集全部固定。由同一个 canonical 分数矩阵生成 `ρ=0`、`ρ=3/9/27` 和严格均衡的结果。在同一组隔离验证样本上构建接近均匀、温和偏斜和明显偏斜的查询批次，保持标签仅用于评价。温度先在独立验证集冻结，再扫 `ρ`，避免两者同时变化造成误判。 [On Calibration of Modern Neural Networks](https://proceedings.mlr.press/v70/guo17a.html)

除总体准确率外，记录宏平均召回、各置信度区间内 `错→对` 和 `对→错` 的数量、不同类别的收益与受损、预测类别翻转和软类别质量。构建可信留出集时应保留分组隔离，并单独报告低置信层，避免只从模型高置信样本中选出一个过于容易的验证集。

## 2. 用可信度控制每行受先验的影响

让模型本身对高可信样本的话语权更大。只用预先冻结的证据构造 $w_i>0$，候选证据包括温度校准后的 top-1 与 top-2 间隔、五视图一致性、分类头与检索一致性。权重控制范围并归一化到均值 1，便于沿用同一数量级的 `ρ`。

$$
\min_{Q_i\in\Delta^{C-1}}\;\frac{1}{N}\sum_i w_i\operatorname{KL}(Q_i\Vert P_i)
+\rho\operatorname{KL}(m\Vert u),\qquad m=\tfrac1N\sum_i Q_i.
$$

一阶条件可写为 $Q_{ic}\propto P_{ic}\exp[-(\rho/w_i)\log(m_c/u_c)]$。当 $w_i$ 不同时，全局列项要按行缩放。求解器需要检验可行性和最优性，并在 $w_i=1$ 时与现有实现一致。先只换 $w_i$，再考虑别的先验。若可靠性分层显示高置信误改没有减少，优先排查权重是否把错误的自信当成可靠证据。

## 3. 给检索和弱图增加证据门控

固定 SCE2 与 SOT1，先改检索，再改查询图。检索端可从邻居组的覆盖数、最近邻与后续邻居的支持差、邻居票的集中度判断可靠性。避免把同一来源的多个近重复样本当成多份独立证据，可比较每组限制票重与按组均匀。图端可按互近邻、分类分布一致性及边权降低跨类别传播，训练检索与查询图应分开消融。

若同一类别有多个姿态或部位，预测一致性门控可能误删真正困难的边。在近重复多、相似异类多、孤立样本多的子集分别报告结果。

## 4. 拆开 SCE2 的教师和损失

用同一个 SP2 父模型、分辨率、训练清单及推理设置，比较旧锚与重训教师导出的新锚分别搭配 `CE`、`CE+ERCE` 的四种完整学生。这里比较的是目标更新与损失的独立贡献及交互。需要更新教师目标时，从适用的父模型重训、重新导出组外监督，再用全部下游训练验证收益。训练教师时仍保持所有评估组隔离，教师与学生的尺度分别校准。

若进一步尝试严格组外锚点，先锁定证据的来源和生成方式，验证组隔离及修正方向，随后只替换锚点。CL1 的整个方案曾经失分，因此优先对准一个可解释的改动，避免再把清洗、去重、监督和训练链同时调整。
