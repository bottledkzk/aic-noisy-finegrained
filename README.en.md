# AIC 2026 · Fine-grained recognition with noisy labels

[中文](README.md)

This repository provides a runnable reference implementation of our AIC 2026 semifinal approach to fine-grained recognition with noisy labels. We selected semi-relaxed optimal transport after testing a soft class-balance penalty against strict balance on the same student and inference inputs. [Competition task](https://www.aicomp.cn/tracks/tracks-1/3714.html)

The training pipeline fine-tunes CLIP ViT-B/32, uses a near-duplicate-group-excluded retrieval bank to build soft training targets, and updates targets with a train-only EMA teacher. The final student learns from targets regenerated by a separately trained teacher. At inference, one student produces five-view features, combines the classifier with nearest-neighbor evidence, and applies a weak mutual-neighbor graph followed by semi-relaxed optimal transport. [Method](docs/method.md)

## Run the examples

Python 3.10 or later is required. The first example compares uncalibrated scores, strict balance, and soft balance on the same synthetic predictions.

```bash
python -m pip install -e .
python -m aic_finegrained demo
```

The image example generates 12 training images with two intentionally wrong labels and six unlabeled query images. A tiny randomly initialized CLIP model runs through all five training stages on CPU. The output directory includes `predictions.csv`, the reusable `canonical.npy` score array, and the five checkpoints.

```bash
python -m pip install -e '.[vision]'
python -m aic_finegrained demo-images --out runs/image-demo
```

These examples demonstrate the pipeline and its numerical behavior. The experiment notes describe the comparisons that informed the final method.
